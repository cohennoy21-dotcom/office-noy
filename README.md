# מעקב פניות נוי כהן

עמוד למעקב אחרי פניות של לקוחות שמתעניינים בשירותי ניהול משרד מרחוק.

## מה יש בעמוד

* **סיכום:** פניות, פגישות היכרות, סגירות, הכנסה חודשית קבועה, למי צריך לחזור, מאיפה הגיעו הפניות, אילו חבילות נבחרו ולמה פניות לא נסגרו.
* **פניות:** חיפוש, סינון לפי סטטוס ועדכון כל פנייה במקום.
* **פנייה חדשה:** טופס להוספת פנייה.

## קבצים

* `index.html` העמוד עצמו
* `lockup.jpg` הלוגו

## הערה חשובה

העמוד נבנה כ Artifact ב Claude ושומר את הנתונים דרך `window.claude` (מסד הנתונים של ה Artifact).
אם פותחים את הקובץ מחוץ ל Claude, למשל ב GitHub Pages, העיצוב יוצג אבל הנתונים לא ייטענו ולא יישמרו.
כדי שיעבוד גם מחוץ ל Claude צריך להחליף את שכבת הנתונים, למשל ב Google Sheets, Firebase או Supabase.
